# アキモト・プライベート・デンタルオフィス PR動画

30秒のプロモーション動画（Remotion製）

## 動画の構成

| シーン | 時間 | 内容 |
|--------|------|------|
| オープニング | 0-5秒 | クリニック名 + キャッチコピー |
| お悩み提示 | 5-10秒 | 患者様の悩み |
| 特徴紹介 | 10-18秒 | 4つの強み |
| 診療内容 | 18-24秒 | 提供サービス |
| 連絡先 | 24-30秒 | アクセス情報 |

## セットアップ

```bash
npm install
```

## プレビュー（ブラウザ）

```bash
npm run studio
```

ブラウザで http://localhost:3000 を開いてリアルタイムプレビューできます。

## MP4動画の生成

```bash
npm run render
```

→ `out/clinic-pr.mp4` が生成されます

## 出力仕様

- 解像度: 1920x1080 (Full HD)
- フレームレート: 30fps
- 長さ: 30秒
- 形式: MP4

## カスタマイズ

`src/ClinicPR.tsx` を編集して内容を変更できます。

- `colors`: 色設定
- `Opening`: オープニングシーン
- `Problems`: お悩みシーン
- `Features`: 特徴シーン
- `Services`: 診療内容シーン
- `Contact`: 連絡先シーン
